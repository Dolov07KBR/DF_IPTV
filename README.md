## Telegram-бот для продажи VPN

Добавлен пример Telegram-бота `vpn_sales_bot.py` с базовой логикой продаж VPN:

- просмотр тарифов (`/plans`);
- создание заказа;
- отправка подтверждения оплаты;
- ручное подтверждение оплаты администратором;
- автоматическая отправка VPN-ключа клиенту.

### Быстрый старт

1. Установить зависимости:

```bash
pip install -r requirements.txt
```

2. Скопировать переменные окружения:

```bash
cp .env.example .env
```

3. Заполнить `.env`:

- `BOT_TOKEN` — токен бота от BotFather;
- `ADMIN_CHAT_ID` — Telegram ID администратора;
- `DB_PATH` — путь к SQLite БД.

4. Запустить бота:

```bash
python vpn_sales_bot.py
```

> Важно: это шаблон. Перед продакшеном добавьте реальную интеграцию платежей,
> аудит действий, защиту от фрода и юридически корректные оферту/политику.
