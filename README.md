Бесплатные IPTV-плейлисты и фирменное Android-приложение **DF IPTV_07** для телефонов, планшетов, Android TV и Fire TV. Оформление — в фирменном стиле сайта [dolov07kbr.github.io](https://dolov07kbr.github.io): тёмный космос `#0b1020`, градиент фиолетовый `#8b5cf6` → циан `#22d3ee`, логотип DF как на сайте.

## 📱 DF IPTV_07 для Android

В каталоге [`android`](android/) находится самостоятельное приложение, написанное с нуля на Kotlin, Jetpack Compose и Android Media3. Код распространяется по GPL-3.0. Код и ресурсы Televizo не используются — реализован сопоставимый набор возможностей собственной разработкой.

### Возможности (в духе Televizo)

- **Все плейлисты репозитория встроены в APK**: `DF_IPTV.m3u`, `07.m3u`, `10.m3u`, `11.m3u`, `12.m3u`, `film.m3u` (~17 000 каналов и фильмов);
- **менеджер плейлистов**: свои M3U по URL, добавление/удаление/обновление;
- **категории и логотипы каналов**: лента категорий, иконки каналов с кэшем;
- **избранное и «недавно смотрели»** с сохранением на устройстве;
- **поиск** по названию и категории по всем плейлистам;
- **плеер Media3**: HW/SW-переключатель декодера, масштаб (вписать/заполнить/обрезать), скорость 0.5–2×, выбор аудиодорожек и субтитров, картинка-в-картинке, переключение каналов (prev/next), возобновление с места остановки, повтор при ошибке;
- **EPG (телегид)**: опциональный XMLTV по URL — «сейчас/далее» в списке и в плеере;
- **родительский контроль**: PIN и блокировка категорий, выключен по умолчанию;
- **Android TV / Fire TV**: leanback-запуск, управление пультом, фирменный TV-баннер;
- **фирменный стиль сайта**: логотип DF в иконке (adaptive + round), на главном экране и в TV-баннере.

### Сборка APK

GitHub Actions собирает debug-APK при пуше в `main`/`arena/**` и в pull request (workflow [`android-iptv.yml`](.github/workflows/android-iptv.yml)). Готовый APK — в артефактах запуска **Actions → Build DF IPTV_07 APK → DF-IPTV-07-debug-APK**. Локально: `cd android && ./gradlew assembleDebug`.

Бесплатные IPTV-плейлисты 2025–2026: свежие и рабочие ссылки в формате M3U.

Скачивайте удобные и стабильные IPTV-плейлисты, которые периодически обновляются. Все плейлисты представлены в формате M3U и включают каналы в HD-качестве, фильмы, радио и музыку.

Плейлисты рассортированы для удобства:

- **По тематикам:** развлекательные, познавательные, спортивные, детские, фильмы.
- **По странам:** Россия, Украина, Беларусь, Европа.
- **По качеству:** HD, 60 FPS.

## ▶️ Как использовать

1. Скопируйте прямую ссылку на нужный `.m3u`-файл в этом репозитории (кнопка **Raw**).
2. Откройте эту ссылку в любом IPTV-плеере (VLC, IPTV Smarters, TiviMate, Kodi и т.п.) как источник плейлиста — или добавьте её в DF IPTV_07 как свой плейлист.
3. Плеер автоматически подтянет список каналов.
